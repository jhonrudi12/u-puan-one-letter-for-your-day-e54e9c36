My day in one letter: **D**.

## The word behind the letter

**D is for Doomscrolled.** I opened my phone "for a second" to check the news,
then looked up and it was 3 a.m., the same bad headlines on loop, my thumb still
scrolling on autopilot. Woke up tired, and did it again over breakfast.

It is vivid (a glowing screen in a dark room at 3 a.m.), it is funny because it
is painfully familiar, and it is true — an honest report of an ordinary day in
2026, not a performance. The letter fits the word: D for Doomscrolled, the
sound of the thumb going down, down, down.

## The entry

`entry.txt` holds exactly one character — `D` — and nothing else: no word, no
gloss, no punctuation. `main.py` (Python 3.13, stdlib only, no network) writes
that single letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and
validates that it is exactly one letter from A to Z.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt  # D
```
